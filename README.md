# GRAVITAS MECHANICA (重力沉压俄罗斯方块)

一个结合了古典素描画风与离散材料物理引擎的俄罗斯方块变种。

与传统俄罗斯方块不同，本作引入了 **重力 (Gravity)**、**材料硬度 (Material)** 和 **历史行链接强度 (Link)** 三个物理变量。当已消除的“历史行”承受的顶部压力超过其链接阈值时，它会瓦解、沉降，并再次填补底部的空白。
